# Surf API SDKs

Official client libraries for the [Surf API](https://developers.surf.social).

| Language | Package | Status |
|----------|---------|--------|
| Python | `pip install surf-api` | Beta |
| TypeScript | `npm install @surf/api` | Coming soon |
| Go | `go get github.com/Flipboard/surf-sdks/go` | Coming soon |

## Getting Started

1. [Apply for developer access](https://developers.surf.social/devportal/v1/developer/apply)
2. Create an application and generate an API token
3. Install the SDK for your language
4. Start building!
